Подключение PostgreSQL

УЗ в БД ≠ админ веб-интерфейса
Нужна отдельная учётная запись PostgreSQL с правами на базу приложения. Если УЗ ещё нет — вкладка «Создать УЗ и базу» (потребуются права superuser, пароль superuser не сохраняется). Подробный runbook: установка ОС → PostgreSQL → эта форма — в документации деплоя.
SELECT 1 · OK · права на schema public
Superuser используется один раз для CREATE USER / CREATE DATABASE / GRANT и не сохраняется в NovaTIP.
-- Эквивалент в psql (если создаёте вручную по runbook): CREATE USER novatip WITH PASSWORD 'CHANGE_ME_STRONG'; CREATE DATABASE novatip OWNER novatip ENCODING 'UTF8'; GRANT ALL PRIVILEGES ON DATABASE novatip TO novatip;
